floe docs

Generated straight from the source on every push — nothing here is a hand-maintained spec.

  • floe-dto

    The wire schema shared by the server and client: UtxoJson, Page, DatumJson, ScriptJson, AddressJson, ErrorBody. Start here if you're writing a client.

  • schema.json

    Machine-readable JSON Schema for the same types, generated by floe-dto's schema example — not a separately-maintained spec.

  • floe-server

    The floe binary: indexer, HTTP API. See the http module for routes and content negotiation (JSON/CBOR). (Docs directory is floe, not floe_server -- the crate's [lib] name is pinned to floe so use floe::... keeps working.)

  • floe-client

    Reference CLI client against the HTTP API.
